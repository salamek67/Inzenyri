# Changelog

Nové položky přidávej pod Android. Při bumpu aplikace je skript vloží do GitHub Release a odstraní je z tohoto souboru ve stejném commitu.

## Android
- Procvičování podporuje kartičky s otočením odpovědi, vlastním hodnocením a opakováním neosvojených kartiček.
- U úkolů, testů i akcí lze zvolit čas; bez času zůstávají celodenní.
- Při vysouvání klávesnice v doplňovacích testech neproblikává bílé pozadí okna.
- Lokálně uložený průběh a výsledky kvízů se automaticky promazávají po 90 dnech bez procvičování; uchovává se nejvýše 200 kvízů.
- Stahování aktualizace zobrazuje přímo u verze tečkovaný ukazatel průběhu a procenta.
