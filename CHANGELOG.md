# Changelog

Nové položky přidávej pod Android. Při bumpu aplikace je skript vloží do GitHub
Release a odstraní je z tohoto souboru ve stejném commitu.

## Android

- Procvičování podporuje offline zeměpisné mapy s výběrem oblastí a umístěním
  špendlíku; po vyhodnocení ukáže správné řešení.

- Sjednoceno formátování zdrojů aplikace beze změny jejího chování.
- Aplikace občas upozorní na dostupnou aktualizaci i na pozadí; upozornění lze
  samostatně vypnout v nastavení.
