# Changelog

Nové položky přidávej pod Android. Při bumpu aplikace je skript vloží do GitHub
Release a odstraní je z tohoto souboru ve stejném commitu.

## Android
- V testech lze procvičovat cizojazyčná podstatná jména včetně členu.
- Tlačítko procvičování se zobrazuje jen u testů, které ho obsahují.
- Ikona maintainer účtu používá instalatérský klíč.
- Po úspěšném pushi databáze se aplikace vrátí na hlavní obrazovku.
